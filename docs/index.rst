SINGr documentation
===================

SINGr or Signal Integrity ngSPICE Analyser is a Python package intended to be used for automated SPICE
simulations and analysis. This currently includes waveform and eye analyses and allows users to specify
and build large simulations without writing large netlists and allows deep parametrisation without needing
to manually implement parameter sweeps and put in the effort to configure specific parameters more manually.
