SINGr
=====
The SINGr package consists in only one module which splits all functionalities
into submodules.

The package is installed using `pip install SINGr` and can be imported using
`import SINGr` with submodules imported as per usual like so `from SINGr import eye_tools`
or `from SINGr.composition import Composition.` 

For further information on usage refer to the examples found in the examples
directory of the repo and the Examples page in the docs for an explanation.
